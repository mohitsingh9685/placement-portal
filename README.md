A production-level placement management system built to streamline the recruitment process for students, recruiters, and administrators with a strong focus on scalability, security, and performance.

🔹 Key Features:
• Secure JWT Authentication with HTTP-only cookies
• Google OAuth Integration
• Role-Based Access Control (Student/Admin)
• Company & Job Management
• Student Application Tracking
• Advanced Filtering System (CGPA, backlog, branch, etc.)
• Resume & JD Upload using AWS S3
• Profile Image Management using Cloudinary
• Redis Caching for improved performance
• Fully Responsive Dashboard UI

🛠 Tech Stack:
• Frontend: React.js, Tailwind CSS
• Backend: Node.js, Express.js
• Database: MongoDB, Mongoose
• Authentication & Security: JWT, bcrypt, Google OAuth, Rate Limiting, CORS
• Cloud & Storage: AWS S3, Cloudinary
• Performance: Redis
• Deployment: Vercel & Render
